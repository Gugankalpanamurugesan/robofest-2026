# ROBOFEST 2026 — ROBOTiX NIT Raipur (student concept)

A responsive frontend landing-page concept created by Gugan, first-year B.Tech Biomedical Engineering student at NIT Raipur.

## Run locally
1. Download and extract this folder.
2. Open the `robofest-gugan` folder in Visual Studio Code.
3. Open `index.html` in a browser, or install the **Live Server** extension and choose **Open with Live Server**.
4. No compiler, MinGW, Node.js or backend is required.

## Files
- `index.html` — page content and semantic structure
- `style.css` — layout, colours, responsive rules, illustration and animation
- `script.js` — mobile navigation interaction

## Theme and design choices
Cybernetic editorial style: deep navy background, cyan accents, technical mono labels, grid motifs, a CSS-built robot illustration, and responsive cards. The page uses HTML, CSS and vanilla JavaScript to keep the source approachable for a beginner.

## Important content note
This is an independent student concept page, not an official ROBOTiX/ROBOFEST website. The three challenge cards (Line Follower, Robo Sumo, Innovation Expo) are illustrative concepts, not a verified 2026 event schedule. Confirm official event names, rules, dates, eligibility and registration links with the organisers before presenting them as official. The registration CTA links to the supplied ROBOTiX ROBOFEST page and this demo does not collect personal information.
